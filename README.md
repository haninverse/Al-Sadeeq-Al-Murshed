## ✦ About the Project

**Al-Sadeeq Al-Murshed | الصديق المرشد** is a student-focused educational support platform concept. Its goal is to connect students who need help understanding course material with knowledgeable student volunteers who can explain challenging topics and support their peers.

The project includes multiple interface screens and an **interactive Figma prototype** that demonstrates how users navigate through the experience.

## ✦ Project Concept

The platform aims to:
- Make it easier for students to seek help with difficult course concepts.
- Encourage peer-to-peer learning and collaboration.
- Provide a structured digital experience for educational support.

## ✦ Design Work

- **UI/UX design** for an Arabic-language educational platform.
- **Multi-screen interface design** covering different parts of the user journey.
- **Interactive prototyping** to demonstrate navigation between screens.
- **Figma** for interface design and prototype interactions.
